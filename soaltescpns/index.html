Kebijakan Privasi — Soal Tes CPNS

Berlaku sejak 22 Agustus 2026

Soal Tes CPNS adalah aplikasi latihan Seleksi Kompetensi Dasar (SKD) yang dikembangkan oleh Lumen Studio. Halaman ini menjelaskan bagaimana aplikasi memperlakukan data Anda.

Ringkasnya

Aplikasi ini tidak mengumpulkan data pribadi apa pun. Tidak ada akun, tidak ada pendaftaran, dan tidak ada data yang dikirim ke server mana pun.

Data yang disimpan di perangkat Anda

Agar progres belajar tidak hilang, aplikasi menyimpan beberapa hal di penyimpanan lokal perangkat Anda sendiri:

  • riwayat tryout beserta skornya
  • jawaban pada tryout yang belum selesai
  • soal yang Anda tandai
  • preferensi tampilan seperti mode gelap dan ukuran teks

Data ini tidak pernah meninggalkan perangkat Anda. Kami tidak dapat melihatnya. Menghapus progres lewat menu Pengaturan, atau menghapus aplikasi, akan menghapus data tersebut sepenuhnya.

Izin aplikasi

Aplikasi tidak meminta izin akses lokasi, kamera, mikrofon, kontak, maupun penyimpanan eksternal. Seluruh soal sudah tersimpan di dalam aplikasi sehingga koneksi internet tidak diperlukan untuk menggunakannya.

Layanan pihak ketiga

Aplikasi tidak memuat iklan, tidak memakai layanan analitik, dan tidak menyertakan pelacak pihak ketiga.

Anak-anak

Aplikasi ini ditujukan bagi peserta seleksi CASN dewasa. Karena tidak ada data yang dikumpulkan, tidak ada data anak yang terkumpul pula.

Perubahan kebijakan

Bila kebijakan ini diperbarui, tanggal berlakunya di bagian atas halaman akan ikut diperbarui.

Kontak

Pertanyaan mengenai kebijakan ini dapat dikirim ke support@lumenstudioapp.com.

Soal Tes CPNS berisi soal latihan yang disusun mengikuti kisi-kisi resmi SKD. Aplikasi ini bukan produk resmi dan tidak berafiliasi dengan Badan Kepegawaian Negara (BKN) maupun Kementerian PANRB.
