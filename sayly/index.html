Kebijakan Privasi

Aplikasi: Sayly
Berlaku sejak: 19 Juli 2026

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Sayly ("aplikasi", "kami") memperlakukan informasi Anda. Kami menghormati privasi Anda dan merancang aplikasi ini agar bekerja sepenuhnya di perangkat Anda.

1. Data yang Kami Kumpulkan

Kami tidak mengumpulkan data pribadi apa pun. Aplikasi ini tidak meminta nama, email, nomor telepon, lokasi, kontak, foto, atau identitas lainnya. Aplikasi juga tidak memerlukan pembuatan akun atau proses masuk (login).

2. Data yang Tersimpan di Perangkat

Aplikasi menyimpan sebagian data secara lokal di perangkat Anda, yaitu kemajuan belajar (pelajaran yang selesai, skor kuis, dan streak harian). Data ini:

  • Hanya disimpan di perangkat Anda;
  • Tidak dikirim ke server mana pun atau ke kami;
  • Akan terhapus jika Anda menghapus (uninstall) aplikasi.

3. Koneksi Internet

Aplikasi ini bekerja sepenuhnya secara offline. Seluruh materi pelajaran sudah disertakan di dalam aplikasi, sehingga tidak ada data yang dikirim atau diterima melalui internet.

4. Layanan Pihak Ketiga

Aplikasi ini tidak menggunakan layanan analitik, iklan, atau layanan pihak ketiga lain yang mengumpulkan data. Tidak ada pelacakan (tracking) dalam bentuk apa pun.

5. Privasi Anak

Aplikasi ini aman digunakan oleh segala usia karena tidak mengumpulkan data pribadi apa pun.

6. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan ditampilkan pada halaman ini dengan pembaruan tanggal "Berlaku sejak" di atas.

7. Kontak

Jika ada pertanyaan mengenai Kebijakan Privasi ini, silakan hubungi kami di:
